# Capturas-Trading-ALFA

Repositorio independiente para guardar capturas de TradingView y documentar análisis del laboratorio ALFA OMEGA. Este repositorio no contiene ni modifica el código del indicador.

## Cómo subir una captura desde Android

1. Abre la carpeta de la temporalidad correspondiente.
2. Pulsa **Add file → Upload files**.
3. Selecciona la captura desde la galería o archivos del teléfono.
4. Usa el formato de nombre indicado abajo y confirma **Commit changes**.

## Nombre recomendado

`BTCUSDT_15m_2026-11-24_0830_contexto.png`

Incluye símbolo, temporalidad, fecha, hora y una palabra breve sobre lo que muestra. Usa hora de Colombia y evita espacios o caracteres especiales.

## Carpetas

- `BTCUSDT/1m`, `5m`, `15m`, `1h`, `4h`, `1D`: capturas por temporalidad.
- `INDICADORES`: configuración y comportamiento de indicadores.
- `ENTRADAS`: posibles entradas y su contexto.
- `SALIDAS`: cierres, objetivos y stops.
- `ERRORES`: errores visuales, señales falsas o problemas de configuración.

## Para analizar una imagen en ChatGPT

GitHub sirve para almacenar y organizar. No garantiza que ChatGPT pueda abrir o interpretar automáticamente cada archivo del repositorio. Para asegurar el análisis, adjunta la imagen directamente en el chat. También puedes compartir el enlace directo del archivo si es público y accesible.

## Privacidad y calidad

- No subas claves API, contraseñas, datos personales ni información de cuentas.
- Conserva visible el símbolo, la temporalidad, la escala de precios y las velas relevantes.
- No recortes la zona necesaria para entender el contexto.
- Una captura permite análisis visual, pero no sustituye datos OHLCV ni un backtest.
